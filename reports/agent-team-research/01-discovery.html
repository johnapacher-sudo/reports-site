一句话定位

AI-Agent-Team 是一个 Claude Code 技能/插件包，提供 6 个专业角色的 AI 智能体配置（PM、前端开发、后端开发、QA、DevOps、Tech Lead）、Thread Manager 语义搜索 MCP Server 以及多种实用工具技能，帮助开发者通过 Claude Code 快速组建 AI 协作团队完成软件开发全流程。

核心特性

  1. 6 个专业角色智能体（Role-Based Agents） - 提供 PM（产品经理）、Frontend Developer（前端开发）、Backend Developer（后端开发）、QA Engineer（测试工程师）、DevOps Engineer（运维工程师）、Tech Lead（技术负责人）6 个预配置的 Claude Code Agent 配置文件，每个角色拥有独立的系统指令、工具权限和工作流程定义，通过 /pm、/fe、/be、/qa、/ops、/tl 快捷命令一键调用。

  2. Thread Manager MCP Server（线程管理器） - 内置 MCP（Model Context Protocol）Server，基于 SQLite 数据库和 Xenova/all-MiniLM-L6-v2 本地向量嵌入模型实现语义搜索，支持跨线程的知识检索和上下文管理，为多智能体协作提供持久化的知识共享层。

  3. 实用工具技能集（Utility Skills） - 包含 DrawNote（可视化笔记生成器，通过 Mermaid 语法生成架构图和流程图）、TidyMyDesktop（桌面文件自动整理工具）、Changelog Generator（变更日志生成器）、SoftCopyright（软件著作权申请材料生成器）4 个实用工具技能。

  4. 即装即用的 npm 分发（npm Distribution） - 通过 npm install -g ai-agent-team 一键安装，再执行 ai-agent-team init 初始化配置，自动生成 .claude/ 目录下的 agents、skills、mcp-servers 等文件，零手动配置即可使用。

  5. Claude Code 原生集成（Claude Code Native） - 完全基于 Claude Code 的 Agent 和 Skill 体系构建，无需额外框架或运行时，直接作为 Claude Code 的扩展插件运行，支持 .claude/agents/*.md 自定义智能体配置格式。

技术栈定位

  • 所属领域： AI 辅助开发工具 / Claude Code 插件生态
  • 解决的核心问题： 为 Claude Code 用户提供预配置的专业角色智能体和协作工具，降低多角色 AI 协作的开发门槛
  • 替代/竞品技术： Claude Code 原生自定义 Agents、Cursor Rules、Cline（VS Code 插件）、Aider（AI 编程助手）
  • 依赖的上游技术： Claude Code CLI、Anthropic Claude API、MCP（Model Context Protocol）、SQLite、Xenova/transformers（本地向量嵌入）
  • 下游使用者/集成方： 使用 Claude Code 进行软件开发的个人开发者和团队
