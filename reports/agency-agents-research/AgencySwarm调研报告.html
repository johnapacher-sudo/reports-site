2.2 核心组件

Agent 类

from agency_swarm import Agent, ModelSettings

agent = Agent(
    name="CEO",
    description="负责客户端通信、任务规划和管理。",
    instructions="你必须与其他 Agent 协作以确保任务完成。",
    files_folder="./files",           # 文件上传目录
    tools_folder="./tools",           # 自定义工具目录
    schemas_folder="./schemas",       # OpenAPI Schema 目录
    tools=[my_custom_tool],           # 工具列表
    model="gpt-5.2",                  # 模型选择
    model_settings=ModelSettings(
        max_tokens=25000,
        temperature=0.7
    ),
)

2.3 通信机制

send_message 工具

send_message 是 Agent 间通信的核心机制：

class SendMessage(FunctionTool):
    """
    用于 Agent 间直接、同步通信的工具。
    """

    sender_agent: "Agent"
    recipients: dict[str, "Agent"]
    _runtime_state: "AgentRuntimeState | None"
    _pending_per_thread: dict[int | None, set[str]]
    _pending_lock: asyncio.Lock

关键特性： - 同步通信：发送消息并等待响应 - 线程安全：防止并发消息冲突 - Enum 验证：接收者名称使用 Enum 验证 - 支持流式：支持流式和非流式模式

使用示例：

# Agent 自动获得 send_message 工具
# 当 Agent 调用 send_message 时：
# 1. 验证接收者名称
# 2. 创建上下文
# 3. 调用接收者的 get_response()
# 4. 返回响应

通信流操作符

使用 > 操作符定义通信流：

# 定义通信流
communication_flows = [
    ceo > dev,           # CEO 可以向 Developer 发送消息
    ceo > va,            # CEO 可以向 VA 发送消息
    dev > va,            # Developer 可以向 VA 发送消息
]

# 链式通信流
communication_flows = [
    ceo > dev > tester,  # CEO -> Developer -> Tester
]

2.4 工具系统

方式 1: @function_tool 装饰器（推荐）

from agency_swarm import function_tool

@function_tool
def my_custom_tool(example_field: str) -> str:
    """工具功能的简短描述。"""
    return f"结果: {example_field}"

方式 2: BaseTool 类

from agency_swarm.tools import BaseTool
from pydantic import Field

class MyCustomTool(BaseTool):
    """工具功能的简短描述。"""

    example_field: str = Field(
        ...,
        description="字段描述..."
    )

    def run(self):
        """工具的主要功能实现。"""
        return "MyCustomTool 操作结果"

方式 3: OpenAPI Schema 导入

from agency_swarm.tools import ToolFactory
import requests

tools = ToolFactory.from_openapi_schema(
    requests.get("https://api.example.com/openapi.json").json()
)

2.5 状态持久化

ThreadManager

class ThreadManager:
    """管理消息存储和持久化。"""

    def __init__(
        self,
        load_threads_callback: ThreadLoadCallback | None = None,
        save_threads_callback: ThreadSaveCallback | None = None,
    ):
        self._store = MessageStore()
        self._load_threads_callback = load_threads_callback
        self._save_threads_callback = save_threads_callback

使用示例

def load_messages() -> list[dict]:
    # 从数据库/文件加载
    return json.loads(open("messages.json").read())

def save_messages(messages: list[dict]) -> None:
    # 保存到数据库/文件
    with open("messages.json", "w") as f:
        json.dump(messages, f)

agency = Agency(
    ceo,
    communication_flows=[ceo > dev],
    load_threads_callback=load_messages,
    save_threads_callback=save_messages,
)

四、关键特性对比

4.1 两个项目的关系

维度 Agency Swarm Agency Agents
定位 编排框架 Agent 模板
技术 Python 库 Markdown 文件
用途 构建多 Agent 系统 使用现成的 Agent 角色

4.2 与其他框架对比

vs LangChain

维度 Agency Swarm LangChain
定位 Agent 编排 通用 LLM 框架
通信 原生 send_message 需要额外组件
工具 Pydantic 类型安全 函数调用
持久化 ThreadManager 内置 需要集成
OpenAI 集成 原生 SDK 适配层

vs AutoGen

维度 Agency Swarm AutoGen
基础 OpenAI Agents SDK 自建框架
语言 Python Python
通信 send_message 同步 异步消息
类型安全 Pydantic 强类型 弱类型
多 LLM LiteLLM 需要适配

vs RuFlo

维度 Agency Swarm RuFlo
基础 OpenAI Agents SDK Claude Code
Agent 数量 自定义 60+ 内置
MCP 工具 无 259 内置
拓扑 通信流定义 4 种拓扑
自学习 无 完整学习循环
记忆 ThreadManager AgentDB + HNSW
