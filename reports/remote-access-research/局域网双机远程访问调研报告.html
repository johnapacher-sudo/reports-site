一、需求分析

1.1 场景描述

┌─────────────┐                    ┌─────────────┐
│   电脑 A     │                    │   电脑 B     │
│  (macOS/Win) │                    │  (macOS/Win) │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │    ┌──────────────────────┐      │
       └───→│    同一局域网/WiFi    │←────┘
            └──────────────────────┘
                    │
                    ▼
        ┌─────────────────────────────┐
        │  互相访问并执行终端指令   │
        │                             │
        │  A → B: A 登录 B，执行命令  │
        │  B → A: B 登录 A，执行命令  │
        └─────────────────────────────┘

1.2 核心需求

需求 说明
双向访问 A 可以访问 B，B 也可以访问 A
终端执行 能够远程执行命令行指令
文件传输 可选：能够传输文件
安全性 需要身份验证，防止未授权访问
易用性 配置简单，日常使用方便

二、方案对比

2.1 主流方案

方案 协议 优点 缺点 推荐度
SSH TCP 22 原生支持、安全、功能完整 需要命令行基础 ⭐⭐⭐⭐⭐
RDP TCP 3389 图形界面、Windows 原生 仅 Windows，带宽占用高 ⭐⭐⭐
VNC TCP 5900 跨平台图形界面 带宽占用高，需额外安装 ⭐⭐⭐
TeamViewer 私有协议 易用、穿透 NAT 商用限制、需安装客户端 ⭐⭐
AnyDesk 私有协议 易用、性能好 商用限制、需安装 ⭐⭐
Rustdesk 开源协议 开源免费、自建服务器 需配置中继服务器 ⭐⭐⭐

2.2 推荐选择: SSH

理由: - macOS / Linux 原生支持，Windows 10+ 内置 OpenSSH - 安全可靠，使用加密传输 - 功能完整：远程执行、文件传输、端口转发 - 轻量级，带宽占用低 - 免费，无需额外软件

3.2 SSH 能做什么

功能 命令 说明
远程登录 ssh user@host 登录到远程主机
执行单条命令 ssh user@host "command" 不登录直接执行
文件传输 scp file user@host:/path 复制文件
安全文件传输 rsync -avz src/ user@host:dst/ 同步文件
端口转发 ssh -L local:remote:port user@host 隧道代理
反向隧道 ssh -R remote:local:port user@host 让远程访问本地

八、免密登录配置

8.1 为什么配置免密登录？

优点:
✅ 无需每次输入密码
✅ 更安全（密钥比密码更难破解）
✅ 脚本自动化友好
✅ 双向互访更方便

8.2 生成 SSH 密钥对

在 A 电脑上执行:

# 生成密钥（一路回车使用默认设置）
ssh-keygen -t rsa -b 4096

# 查看生成的密钥
ls -la ~/.ssh/
# id_rsa      - 私钥（保密！）
# id_rsa.pub  - 公钥（需要复制到 B 电脑）

8.3 复制公钥到 B 电脑

方法一：使用 ssh-copy-id（推荐）

# 在 A 电脑执行
ssh-copy-id username@B的IP

# 示例
ssh-copy-id john@192.168.1.200

方法二：手动复制

# 在 A 电脑查看公钥
cat ~/.ssh/id_rsa.pub

# 复制输出内容，然后在 B 电脑执行
mkdir -p ~/.ssh
echo "粘贴公钥内容" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

8.4 测试免密登录

# 在 A 电脑测试连接 B
ssh username@B的IP

# 如果不需要输入密码直接登录，配置成功！

8.5 双向免密登录

┌─────────────────────────────────────────────────────────────────────────┐
│                     双向免密登录配置流程                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Step 1: 在 A 电脑生成密钥                                               │
│          ssh-keygen -t rsa -b 4096                                      │
│                                                                         │
│  Step 2: A 的公钥复制到 B                                                │
│          ssh-copy-id userB@B_IP                                         │
│                                                                         │
│  Step 3: 在 B 电脑生成密钥                                               │
│          ssh-keygen -t rsa -b 4096                                      │
│                                                                         │
│  Step 4: B 的公钥复制到 A                                                │
│          ssh-copy-id userA@A_IP                                         │
│                                                                         │
│  Step 5: 测试双向连接                                                    │
│          A: ssh userB@B_IP  ✓ 免密登录                                  │
│          B: ssh userA@A_IP  ✓ 免密登录                                  │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

8.6 配置文件简化

编辑 ~/.ssh/config:

# 在 A 电脑配置
Host b
    HostName 192.168.1.200
    User john
    IdentityFile ~/.ssh/id_rsa

# 在 B 电脑配置
Host a
    HostName 192.168.1.100
    User mary
    IdentityFile ~/.ssh/id_rsa

简化后连接:

# 原来
ssh john@192.168.1.200

# 现在
ssh b

九、安全注意事项

9.1 基础安全措施

措施 说明 操作
强密码 使用复杂密码 密码长度 12+，包含大小写数字符号
密钥认证 优先使用密钥 禁用密码登录
限制用户 只允许特定用户 AllowUsers user1 user2
更改端口 避免默认端口 Port 2222
禁用 root 禁止 root 登录 PermitRootLogin no

9.2 加固 SSH 配置

编辑 /etc/ssh/sshd_config:

# 禁用 root 登录
PermitRootLogin no

# 只允许密钥认证
PasswordAuthentication no
PubkeyAuthentication yes

# 限制登录用户
AllowUsers your_username

# 可选：更改端口
Port 2222

# 限制尝试次数
MaxAuthTries 3

# 空闲超时
ClientAliveInterval 300
ClientAliveCountMax 2

应用配置:

# 修改后重启 SSH 服务
sudo systemctl restart sshd
# 或
sudo launchctl stop com.openssh.sshd
sudo launchctl start com.openssh.sshd

9.3 局域网安全

✅ 局域网相对安全，但仍需注意：

1. 使用强密码/密钥认证
2. 定期更新系统和 SSH
3. 不要转发敏感端口到公网
4. 使用 WiFi 时设置强密码
5. 考虑使用 VPN 进行额外加密

十、故障排查

10.1 连接被拒绝

sudo launchctl list | grep ssh

# 检查防火墙
# macOS

# Linux (ufw)
sudo ufw status

# Linux (firewalld)
sudo firewall-cmd --list-all

# Windows
netsh advfirewall firewall show rule name=all | findstr 22

10.3 权限被拒绝

# 检查 .ssh 目录权限
ls -la ~/.ssh/
# 应该是 700 (drwx------)

chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
chmod 600 ~/.ssh/authorized_keys

# 检查家目录权限
ls -la ~/
# 家目录不应该有写权限给其他人
chmod go-w ~

10.4 常见错误速查表

错误信息 可能原因 解决方案
Connection refused SSH 服务未运行 启动 sshd 服务
Connection timed out 防火墙阻止 检查防火墙规则
Permission denied 密码错误/密钥问题 检查认证方式
Host key verification failed 主机密钥变化 删除 ~/.ssh/known_hosts 对应行
No route to host 网络不通 检查 IP 和网络连接

10.5 调试模式

# 详细输出模式
ssh -v user@host

# 更详细的调试
ssh -vvv user@host

# 测试连接（不登录）
ssh -T user@host

十一、快速配置脚本

11.1 macOS 一键配置

#!/bin/bash
# setup-ssh-mac.sh

echo "=== macOS SSH 配置脚本 ==="

# 检查 SSH 服务状态
if sudo launchctl list | grep -q ssh; then
    echo "✓ SSH 服务已运行"
else
    echo "正在启动 SSH 服务..."
    sudo systemsetup -setremotelogin on
fi

# 获取 IP
IP=$(ipconfig getifaddr en0)
echo "✓ 本机 IP: $IP"

# 生成密钥（如果不存在）
if [ ! -f ~/.ssh/id_rsa ]; then
    echo "正在生成 SSH 密钥..."
    ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""
    echo "✓ 密钥已生成"
else
    echo "✓ 密钥已存在"
fi

echo ""
echo "=== 配置完成 ==="
echo "用户名: $(whoami)"
echo "IP 地址: $IP"
echo ""
echo "从其他电脑连接命令:"
echo "  ssh $(whoami)@$IP"
echo ""
echo "公钥内容（复制到目标机器）:"
cat ~/.ssh/id_rsa.pub

11.2 Windows 一键配置（PowerShell）

# setup-ssh-windows.ps1
# 以管理员身份运行

Write-Host "=== Windows SSH 配置脚本 ===" -ForegroundColor Green

# 检查 OpenSSH Server
$sshServer = Get-WindowsCapability -Online | Where-Object Name -like "OpenSSH.Server*"

if ($sshServer.State -ne "Installed") {
    Write-Host "正在安装 OpenSSH Server..." -ForegroundColor Yellow
    Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
}

# 启动服务
Write-Host "正在启动 SSH 服务..." -ForegroundColor Yellow
Start-Service sshd
Set-Service -StartupType Automatic sshd

# 防火墙规则
$rule = Get-NetFirewallRule -Name "OpenSSH-Server-In-TCP" -ErrorAction SilentlyContinue
if (-not $rule) {
    Write-Host "正在配置防火墙..." -ForegroundColor Yellow
    New-NetFirewallRule -Name "OpenSSH-Server-In-TCP" -DisplayName "OpenSSH Server" -Direction Inbound -Protocol TCP -LocalPort 22 -Action Allow
}

# 获取 IP
$ip = (Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.InterfaceAlias -notlike "*Loopback*" }).IPAddress
Write-Host "✓ 本机 IP: $ip" -ForegroundColor Green

# 生成密钥
if (-not (Test-Path "$env:USERPROFILE\.ssh\id_rsa")) {
    Write-Host "正在生成 SSH 密钥..." -ForegroundColor Yellow
    New-Item -ItemType Directory -Path "$env:USERPROFILE\.ssh" -Force | Out-Null
    ssh-keygen -t rsa -b 4096 -f "$env:USERPROFILE\.ssh\id_rsa" -N ""
}

Write-Host ""
Write-Host "=== 配置完成 ===" -ForegroundColor Green
Write-Host "用户名: $env:USERNAME"
Write-Host "IP 地址: $ip"
Write-Host ""
Write-Host "从其他电脑连接命令:" -ForegroundColor Cyan
Write-Host "  ssh $env:USERNAME@$ip"

十二、使用示例

12.1 基本远程执行

# 登录到 B 电脑
ssh user@192.168.1.200

# 执行单条命令（不登录）
ssh user@192.168.1.200 "ls -la"

# 执行多条命令
ssh user@192.168.1.200 "cd /tmp && ls -la && pwd"

# 使用 sudo
ssh user@192.168.1.200 "sudo apt update"

12.2 文件传输

# 复制文件到远程
scp local_file.txt user@192.168.1.200:/remote/path/

# 从远程复制文件
scp user@192.168.1.200:/remote/file.txt ./local/path/

# 复制整个目录
scp -r local_dir/ user@192.168.1.200:/remote/path/

# 使用 rsync 同步（更高效）
rsync -avz --progress local_dir/ user@192.168.1.200:/remote/dir/

12.3 反向操作（B 访问 A）

# 在 B 电脑上执行，连接 A
ssh user@192.168.1.100

# 执行 A 上的命令
ssh user@192.168.1.100 "your_command"

十三、总结

快速上手清单

□ Step 1: 确认两台电脑在同一网络
     - 检查 IP 是否在同一网段（如 192.168.1.x）

□ Step 2: 开启 SSH 服务
     - macOS: 系统设置 → 远程登录 → 开启
     - Windows: 安装并启动 OpenSSH Server
     - Linux: sudo apt install openssh-server && sudo systemctl start ssh

□ Step 3: 测试连接
     - ssh username@对方IP

□ Step 4: 配置免密登录（推荐）
     - ssh-keygen -t rsa -b 4096
     - ssh-copy-id username@对方IP

□ Step 5: 双向配置
     - 在两台电脑上分别执行 Step 4

场景 推荐配置
