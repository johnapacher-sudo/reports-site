一、项目概述

1.1 什么是 Page-Agent？

Page-Agent 是阿里巴巴开源的 JavaScript 页面内 GUI 智能体，允许用户通过自然语言控制网页界面。

├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   "The GUI Agent Living in Your Webpage"                                │
│                                                                         │
│   🎯 一行代码，让网站变成 AI-Native 应用                                 │
│   🗣️ 用自然语言操控网页，无需学习复杂 API                                │
│   📦 纯前端 JavaScript，无需浏览器扩展/Python/无头浏览器                 │

1.3 与传统方案的区别

传统方案 Page-Agent
需要 Python 环境 纯 JavaScript，无需 Python
需要无头浏览器 (Puppeteer/Playwright) 直接在页面内运行
需要浏览器扩展 无需任何扩展
基于截图的多模态 LLM 基于文本的 DOM 操作
需要特殊权限 无需特殊权限

四、快速开始

五、API 详解

5.1 创建 PageAgent 实例

import { PageAgent } from 'page-agent'

const agent = new PageAgent({
    // LLM 配置
    model: 'qwen3.5-plus',           // 模型名称
    baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1',  // API 端点
    apiKey: 'YOUR_API_KEY',          // API 密钥

    // 可选配置
    language: 'zh-CN',               // 语言设置
    timeout: 30000,                  // 超时时间 (ms)
})

5.2 核心方法

execute(command)

执行自然语言命令：

// 点击操作
await agent.execute('点击登录按钮')

// 表单填充
await agent.execute('在用户名输入框填写 admin')

// 复杂操作
await agent.execute('填写注册表单，用户名是 test，密码是 123456，然后点击提交')

// 查询操作
const result = await agent.execute('获取页面标题')

命令示例

// 导航操作
await agent.execute('点击菜单中的"产品"')
await agent.execute('滚动到页面底部')
await agent.execute('返回上一页')

// 表单操作
await agent.execute('在搜索框输入"Page-Agent"')
await agent.execute('选择下拉框中的"中国"选项')
await agent.execute('勾选"同意条款"复选框')

// 数据提取
await agent.execute('读取商品价格')
await agent.execute('获取表格中所有数据')

// 复杂任务
await agent.execute('登录系统，然后进入个人设置页面')
await agent.execute('将所有商品加入购物车')

5.3 链式调用

// 多步骤任务
await agent.execute('点击登录')
await agent.execute('输入用户名 admin')
await agent.execute('输入密码 123456')
await agent.execute('点击登录按钮')

七、高级用法

7.1 事件监听

const agent = new PageAgent({...})

// 监听执行开始
agent.on('start', (command) => {
    console.log('开始执行:', command)
})

// 监听执行步骤
agent.on('step', (step) => {
    console.log('执行步骤:', step)
})

// 监听执行完成
agent.on('complete', (result) => {
    console.log('执行完成:', result)
})

// 监听错误
agent.on('error', (error) => {
    console.error('执行错误:', error)
})

7.2 自定义动作

const agent = new PageAgent({
    // ... 基础配置

    // 自定义动作
    actions: {
        // 自定义截图动作
        screenshot: async () => {
            // 你的截图逻辑

        },

        // 自定义数据提取
        extractData: async (selector) => {
            const element = document.querySelector(selector)

7.4 React 集成

import { useEffect, useRef } from 'react'
import { PageAgent } from 'page-agent'

function MyComponent() {
    const agentRef = useRef(null)

    useEffect(() => {
        agentRef.current = new PageAgent({
            model: 'qwen3.5-plus',
            baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1',
            apiKey: process.env.REACT_APP_API_KEY,
        })
    }, [])

    const handleCommand = async (command) => {
        await agentRef.current?.execute(command)
    }

    return (
        <div>
            <button onClick={() => handleCommand('点击提交按钮')}>
                执行自动化
            </button>
        </div>
    )
}

九、最佳实践

9.1 安全建议

// ✅ 推荐：使用环境变量存储 API Key
const agent = new PageAgent({
    apiKey: process.env.API_KEY,  // 服务端渲染时注入
})

// ❌ 不推荐：硬编码 API Key
const agent = new PageAgent({
    apiKey: 'sk-xxxxx',  // 不要这样做！
})

9.2 错误处理

try {
    await agent.execute('点击登录按钮')
} catch (error) {
    if (error.name === 'TimeoutError') {
        console.log('操作超时，元素可能不存在')
    } else if (error.name === 'ElementNotFoundError') {
        console.log('找不到目标元素')
    } else {
        console.error('执行失败:', error.message)
    }
}

9.3 性能优化

// 复用 Agent 实例
const agent = new PageAgent({...})

// 批量执行时复用连接
async function batchExecute(commands) {
    for (const cmd of commands) {
        await agent.execute(cmd)
    }
}

9.4 命令编写建议

// ✅ 清晰具体
await agent.execute('点击 ID 为 submit-btn 的蓝色提交按钮')

// ❌ 模糊不清
await agent.execute('点那个按钮')

// ✅ 分步骤执行复杂任务
await agent.execute('点击用户菜单')
await agent.execute('点击设置选项')
await agent.execute('修改密码为 xxx')

// ❌ 一次执行过多操作
await agent.execute('登录然后改密码然后退出')  // 可能失败

十、常见问题

Q1: Page-Agent 是否免费？

A: Page-Agent 本身是开源免费的（MIT 协议），但需要自备 LLM API。Demo 模式提供免费测试 API，仅供评估使用。

Q2: 支持哪些浏览器？

A: 支持所有现代浏览器（Chrome、Firefox、Safari、Edge）。

Q3: 能否在移动端使用？

A: 可以，Page-Agent 是纯 JavaScript，支持移动端浏览器。

Q4: 如何处理动态加载的内容？

A: Page-Agent 会自动等待元素出现，也可以通过配置调整等待时间。

Q5: 与 browser-use 的关系？

A: Page-Agent 基于 browser-use 的 DOM 处理组件和提示词构建，但专为客户端网页增强设计，而非服务端自动化。

Q6: 支持哪些语言？

A: 目前支持中文 (zh-CN) 和英文 (en-US)。
