一句话定位

GStack 是由 Y Combinator CEO Garry Tan 创建的一套包含 23 个固化工具（slash commands）的 Claude Code 技能集，通过模拟 CEO、设计师、工程经理、发布经理、文档工程师和 QA 等虚拟角色，将 Claude Code 转变为一个完整的虚拟工程团队，支持 8 种 AI 编码代理并行冲刺开发。

核心特性

  1. 23 个固化工具（Opinionated Tools / Slash Commands） - 提供覆盖完整开发生命周期的 23+ 个技能命令，包括 /office-hours（办公时间）、/plan-ceo-review（CEO 评审）、/plan-eng-review（工程评审）、/plan-design-review（设计评审）、/review（代码审查）、/qa（质量保证）、/ship（发布）、/design-shotgun（设计发散）、/browse（浏览器）、/cso（首席安全官）、/codex（跨模型分析）、/autoplan（自动规划）、/learn（学习）、/retro（回顾）等。每个技能承担特定的虚拟角色职责。

  2. Sprint 冲刺流程（Think → Plan → Build → Review → Test → Ship → Reflect） - 定义了完整的七步冲刺开发流程。Think 阶段定义问题和目标，Plan 阶段生成工程计划并通过 CEO/工程/设计三轮评审，Build 阶段执行编码，Review 阶段进行代码审查，Test 阶段运行 QA，Ship 阶段发布代码，Reflect 阶段进行回顾总结。每个阶段有对应的技能命令驱动。

  3. 多代理并行冲刺（Multi-Agent Parallel Sprints） - 通过 Conductor 调度器支持 10-15 个 Claude Code 会话同时并行运行不同冲刺。支持 8 种 AI 编码代理：Claude Code、Codex CLI、OpenCode、Cursor、Factory Droid、Slate、Kiro 和 OpenClaw。/pair-agent 技能实现跨代理协调，将任务分发到最适合的代理执行。

  4. GStack Browser（AI 控制浏览器） - 内置基于 Chromium 的 AI 控制浏览器，具备反检测隐身模式（anti-bot stealth）、侧边栏代理（sidebar agent）、Cookie 导入、视觉截图分析能力。支持自动化 Web 测试、页面分析和交互。

  5. 安全护栏（Safety Guardrails） - 提供 /careful（谨慎模式）、/freeze（冻结模式）、/guard（守卫模式）三级安全防护。/investigate 技能在检测到异常时自动冻结。/cso（首席安全官）技能提供安全审计。所有安全操作有完整日志记录。

  6. 跨模型独立审查（Cross-Model Review） - /codex 技能调用 OpenAI 的 Codex 模型对 Claude Code 的输出进行独立审查，提供第二意见。这种双模型交叉验证机制降低了单一模型的盲点和偏见风险。

技术栈定位

  • 所属领域： AI 编码代理 / 技能系统（Skills System）/ 虚拟工程团队（Virtual Engineering Team）/ 冲刺开发（Sprint Development）/ 多代理协调（Multi-Agent Orchestration）
  • 解决的核心问题： 传统 AI 编码工具（如 Claude Code 原生模式）在大型项目中缺乏结构化的角色分工、流程管理和质量保障。开发者需要同时扮演产品经理、架构师、开发者、测试工程师和发布经理等角色。GStack 通过固化工具和冲刺流程将开发过程结构化，让 AI 在每个阶段承担明确角色。同时解决多代理协调问题，让不同 AI 代理并行工作。
  • 替代/竞品技术： BMAD-METHOD（12 代理角色，企业级 SDLC）、GSD2（规格驱动，三级分解）、Superpowers（Skills + 守卫栏，~94K Stars）、Claude Code 原生模式、Cursor Agents、Taskmaster（PRD 优先）
  • 依赖的上游技术： Claude Code（主要宿主环境）/ 其他 7 种 AI 编码代理（Codex CLI、OpenCode、Cursor 等）/ Git / Node.js / Chromium（GStack Browser）/ OpenAI API（/codex 跨模型审查）
  • 下游使用者/集成方： YC 创业公司（S26 批次广泛采用）、独立开发者、软件团队（通过 team mode 自动更新共享仓库）/ OpenClaw 生态（通过 ClawHub 集成 4 个原生技能）
