一、Obsidian 简介

1.1 什么是 Obsidian？

Obsidian 是一款基于 Markdown 的双向链接笔记软件，核心特点：

特性 说明
本地优先 所有数据存储在本地，完全掌控
Markdown 使用标准 Markdown 格式，通用性强
双向链接 笔记之间可以相互引用，形成知识网络
插件生态 丰富的社区插件，高度可定制
跨平台 支持 Windows、macOS、Linux、iOS、Android

1.2 核心理念

│                    Obsidian 设计理念                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   📁 本地存储    ──→  数据完全掌控，隐私安全                  │
│                                                             │
│   🔗 双向链接    ──→  知识网络，而非孤立笔记                  │
│                                                             │
│   🔌 插件系统    ──→  无限扩展可能性                          │
│                                                             │
│   📝 Markdown   ──→  通用格式，永不过时                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘

1.3 适用场景

  • 📚 个人知识管理 (PKM)
  • 📝 学术研究与论文写作
  • 💼 项目管理与任务追踪
  • 📖 读书笔记与文献管理
  • 🧠 第二大脑构建

二、安装与配置

2.1 下载安装

官网: https://obsidian.md

平台 下载方式
Windows 官网下载 .exe 安装包
macOS 官网下载 .dmg 或 Homebrew
Linux AppImage / Flatpak / Snap
iOS App Store
Android Google Play / APK

macOS Homebrew 安装:

brew install --cask obsidian

2.2 创建仓库 (Vault)

首次启动时需要创建或打开仓库：

┌─────────────────────────────────────────┐
│           创建新仓库                     │
├─────────────────────────────────────────┤
│                                         │
│  仓库名称: MyVault                      │
│  存储位置: ~/Documents/MyVault          │
│                                         │
│  [创建仓库]                             │
│                                         │
└─────────────────────────────────────────┘

注意: 仓库就是一个普通文件夹，里面存放 Markdown 文件。

2.3 初始设置

设置项 建议配置
编辑器 > 自动配对括号 ✅ 开启
编辑器 > 智能缩进 ✅ 开启
文件与链接 > 默认存放位置 指定文件夹
外观 > 主题 选择喜欢的主题

三、核心概念

3.1 仓库 (Vault)

MyVault/                    ← 仓库根目录
├── .obsidian/              ← Obsidian 配置目录（自动生成）
│   ├── app.json
│   ├── appearance.json
│   ├── community-plugins.json
│   └── plugins/            ← 插件目录
│
├── 00-Inbox/               ← 收件箱
├── 01-Projects/            ← 项目
├── 02-Areas/               ← 领域
├── 03-Resources/           ← 资源
├── 04-Archives/            ← 归档
├── Templates/              ← 模板
└── Daily Notes/            ← 日记

3.2 笔记 (Note)

每个笔记就是一个 .md 文件：

---
title: 笔记标题
date: 2026-03-14
tags: [tag1, tag2]
---

# 笔记标题

笔记内容...

## 相关链接
- [[相关笔记1]]
- [[相关笔记2]]

3.3 链接类型

链接类型 语法 说明
内部链接 [[笔记名]] 链接到其他笔记
标题链接 [[笔记名#标题]] 链接到笔记的特定标题
块链接 [[笔记名^block-id]] 链接到特定块
外部链接 [显示文本](URL) 链接到网页
嵌入 ![[图片.png]] 嵌入图片或笔记

4.3 文件操作

创建笔记:
  1. 快捷键 Cmd/Ctrl + N
  2. 点击左侧文件列表的"新建笔记"图标
  3. 右键文件夹 → 新建笔记

移动/重命名:
  1. 右键文件 → 重命名/移动
  2. 拖拽文件到目标文件夹

删除:
  1. 右键文件 → 删除
  2. 选中文件按 Delete 键

八、同步方案

8.1 官方同步

Obsidian Sync (付费服务): - 端到端加密 - 版本历史 - 实时同步 - 价格: $4/月

8.2 第三方同步方案

方案 优点 缺点
iCloud 苹果生态无缝集成 仅限 Apple 设备
Dropbox 稳定可靠 免费空间有限
Google Drive 空间大 需要第三方工具
Syncthing 开源免费，P2P 配置较复杂
Git 版本控制 需要技术背景
Remotely Save 支持 S3/WebDAV 需配置

8.3 Git 同步脚本示例

#!/bin/bash
# Obsidian Git 自动同步脚本

VAULT_PATH="$HOME/Documents/MyVault"
cd "$VAULT_PATH"

# 自动提交
git add .
git commit -m "Auto backup: $(date '+%Y-%m-%d %H:%M:%S')"
git push

九、最佳实践建议

9.1 文件夹结构 (PARA 方法)

MyVault/
├── 00-Inbox/        ← 快速收集，定期整理
├── 01-Projects/     ← 当前进行的项目
├── 02-Areas/        ← 持续关注的领域
├── 03-Resources/    ← 有价值的资源
├── 04-Archives/     ← 完成或不再活跃的内容
├── Templates/       ← 模板文件
└── Daily/           ← 日记

9.2 命名规范

# 推荐格式
YYYY-MM-DD-笔记标题.md
2026-03-14-Obsidian使用指南.md

# 项目笔记
项目名-模块-功能.md
MyProject-API-认证设计.md

# 文献笔记
@作者-年份-标题.md
@Smith-2024-AI研究.md
