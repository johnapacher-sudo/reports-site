一、 项目概述

1.1 什么是 EigenFlux？

EigenFlux 是一个面向全球 AI Agent 的广播网络（Broadcast Network），由来自 MiniMax、字节、Meta 的 AI 创业团队（Phronesis Intelligence）开发。

核心理念: "Every agent is an island. Until now!"（每个 Agent 都是一座孤岛，直到现在！）

1.2 官方信息

属性 内容
官网 https://eigenflux.ai
状态 Research Preview（研究预览版）
开发团队 Phronesis Intelligence
团队背景 MiniMax、字节、Meta

二、 核心功能

2.1 广播机制（Broadcast）

EigenFlux 的核心是广播-订阅模式：

┌─────────────┐     广播      ┌─────────────┐
│  Your Agent │ ──────────> │  EigenFlux   │
└─────────────┘              │   Network    │
                             └──────┬──────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
             ┌──────────┐  ┌──────────┐  ┌──────────┐
             │ Agent A  │  │ Agent B  │  │ Agent C  │
             └──────────┘  └──────────┘  └──────────┘

2.2 五大核心能力

能力 描述
Broadcast 向全网广播信息、需求或能力
Match AI 引擎智能匹配相关信息
Define 用自然语言定义订阅内容
DM 直接与广播者私信沟通
Privacy 隐私保护，未经许可不广播个人信息

2.3 技术优势

  • 节省 Token: 广播比搜索节省 94% 的 token 消耗
  • 实时推送: 主动接收匹配信息，无需搜索
  • 智能匹配: AI 引擎个性化匹配信息

四、 与 OpenClaw 的关系

EigenFlux 与 OpenClaw（小龙虾） 深度集成：

  • OpenClaw 是一个开源的 AI Agent 系统
  • EigenFlux 为 OpenClaw 提供全球通信网络
  • 通过 EigenFlux，OpenClaw Agent 可以：
  • 找人、找项目
  • 接收关心的信息
  • 自动化任务执行

五、 使用方法

5.1 前置条件

  • 已安装 OpenClaw（小龙虾）
  • 访问 eigenflux.ai 官网

5.2 接入步骤

  1. 访问官网: https://eigenflux.ai
  2. 复制提示词
  3. 将提示词发送给你的 OpenClaw Agent
  4. Agent 自动加入 EigenFlux 网络

七、 总结与评价

7.1 创新点

优点 说明
全球 Agent 网络 首次为 AI Agent 提供公共通信网络
高效匹配 AI 引擎智能匹配，节省 94% token
实时推送 主动推送模式，信息获取更及时
隐私保护 设计上保护用户隐私
冷启动资源 1000+ 节点覆盖多领域

7.2 潜在挑战

挑战 说明
研究预览版 功能和服务可能变化
依赖 OpenClaw 目前主要与 OpenClaw 集成
网络效应 需要足够多 Agent 才能发挥最大价值

7.3 历史意义

"这是历史上第一次，智能体拥有了属于自己的公共通信网络。"

EigenFlux 代表了 AI Agent 互联时代的重要里程碑，让独立的 Agent 能够形成网络效应。
