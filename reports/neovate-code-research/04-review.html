  • 保留理由： GitHub API 返回的 contributors_count 字段通常不包含在基础仓库信息中，需要额外的 API 调用。当前"Forks: 151"提供了有价值的社区参与度指标，且"Open Issues: 53"补充了项目活跃度信息。数据本身准确（与 GitHub API 一致），只是字段名与模板建议不完全一致。属于排版层面的偏差，不影响信息质量。
