一句话定位

PaperClip 是一个开源的 AI Agent 编排平台（Orchestration Platform），专注于构建"零人类公司"（Zero-Human Company），通过组织架构图（Org Charts）、目标对齐（Goal Alignment）、心跳调度（Heartbeats）、预算控制（Cost Control）和治理机制（Governance）等企业级管理能力，让多个 AI Agent 像一家真正的公司一样协作运转。

核心特性

  1. 自带 Agent（Bring Your Own Agent） - PaperClip 不绑定任何特定的 Agent 框架或运行时。支持 OpenClaw、Claude Code、Codex、Cursor、Bash 脚本、HTTP API 等多种 Agent 类型。核心理念是"If OpenClaw is an employee, Paperclip is the company"——PaperClip 提供的是公司级编排能力，而非单个 Agent 能力。[来源：GitHub README]

  2. 组织架构图与目标对齐（Org Charts & Goal Alignment） - 通过可视化的组织架构图定义 Agent 之间的层级关系和职责分工。目标对齐机制确保每个 Agent 的工作目标与公司整体目标一致，从 CEO 到基层 Agent 形成清晰的目标传递链条。支持董事会级别的治理（Governance），重要决策需要董事会审批。[来源：GitHub README]

  3. 心跳调度与预算控制（Heartbeats & Cost Control） - 心跳机制（Heartbeats）按预设时间表自动唤醒 Agent 执行任务，无需人工触发。预算控制为每个 Agent 设置独立预算，精确追踪 Token 消耗和 API 调用成本，防止成本失控。两者结合实现了自动化运营的核心闭环。[来源：GitHub README]

  4. 工单系统与全链路追踪（Ticket System） - 内置完整的工单系统，每条 Agent 活动都生成可追溯的 Ticket，记录完整的执行链路、决策过程和结果。支持审计（Audit）和事后回溯，解决了多 Agent 系统中"谁做了什么、为什么这样做"的透明度问题。[来源：GitHub README]

  5. 多公司隔离与预构建模板（Multi-Company & Pre-built Companies） - 支持在同一平台上创建和运营多个独立的公司实例，各公司之间的数据、Agent、配置完全隔离。提供 16 个预构建的公司模板（如 Content Marketing Agency 含 8 个 Agent、Crypto Trading Desk 含 12 个 Agent、E-commerce Operator 含 10 个 Agent），覆盖内容营销、加密交易、电商运营、YouTube 生产、开发代理、房地产获客等常见场景，包含 440+ 预配置 Agent 和 500+ 技能。[来源：GitHub README]

技术栈定位

  • 所属领域： AI Agent 编排 / 多 Agent 协作 / 零人类公司 / Agent 基础设施 / AI 自动化运营
  • 解决的核心问题： 当 AI Agent 从"单兵作战"进入"团队协作"阶段时，缺乏企业级的管理和编排工具。PaperClip 解决的核心问题是：如何让多个 AI Agent 像一家真正的公司一样运转——包括组织架构设计、目标传递、成本控制、任务调度、执行追踪和治理审批。它不替代任何 Agent 框架，而是在所有 Agent 之上提供"公司运营"这一编排层。
  • 替代/竞品技术： CrewAI（多 Agent 协作框架）、AutoGen（微软多 Agent 框架）、LangGraph（多 Agent 工作流）、MetaGPT（多 Agent 软件公司模拟）、Agent Protocol（Agent 通信标准）
  • 依赖的上游技术： Node.js 20+、pnpm 9.15+、TypeScript、React、OpenClaw（推荐 Agent 运行时）、多种 LLM API（通过各 Agent 间接使用）
  • 下游使用者/集成方： AI 自动化运营团队、内容营销团队、加密交易团队、电商运营团队、需要多 Agent 协作的企业和创业者
